# 🎮 Ball Roller Game

Welcome to **Ball Roller Game**! Control the ball, avoid obstacles, and navigate through the level to reach your goal. This project was developed as part of my Game Development learning journey.

---

## 📥 Download & Play

### Method 1: Download from GitHub

1. Visit the GitHub repository.
2. Click the **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file to any folder on your PC.

### Method 2: Clone the Repository

```bash
git clone <repository-url>
```

Then navigate to the project folder.

---

## ▶️ How to Run the Game

1. Open the extracted project folder.
2. Locate the game executable file:

```text
My project.exe
```

3. Double-click the executable file to launch the game.

> Note: Windows may display a security warning for downloaded applications. Click **More Info → Run Anyway** if you trust the source.
